This a conosle app that prompt users for a username, password and cell number and validate user input with a login class.
There is restrictions and rules applied to this program.
The username should be 5 characters including a underscore
The password should be more than 8 characters include numbers and special characters
The number should include the country number and cannot exceed the normal phone number character

How to run this project?
Download the project on github as a zip file
You would need an IDE netbeans prefably.
When in netbeams import the zip file and once the project is loaded,
click the green arrow to run the project and follow through the instructions.
